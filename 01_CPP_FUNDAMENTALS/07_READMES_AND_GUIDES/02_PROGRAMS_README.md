# 02_PROGRAMS — 01 CPP FUNDAMENTALS (C++ Source Programs & PDF Code Guides)

This folder contains 3 self-contained C++ source programs for **01 CPP FUNDAMENTALS**, organized into subfolders:

## Subfolders inside `02_PROGRAMS/`
1. [`01_CPP_SOURCE_CODE/`](./01_CPP_SOURCE_CODE/README.md) — All 3 compilable `.cpp` source files (plus intentional `_compile_error.cpp` classroom demonstrations where applicable).
2. [`02_PDF_PROGRAM_GUIDES/`](./02_PDF_PROGRAM_GUIDES/README.md) — Printable, syntax-highlighted PDF reference sheet containing all 3 C++ programs with line-by-line commentary.

## Program List & Compilation Commands
1. [`01_first_classroom_program.cpp`](./01_CPP_SOURCE_CODE/01_first_classroom_program.cpp) — `g++ -std=c++20 -Wall -Wextra -pedantic 01_first_classroom_program.cpp -o 01_first_classroom_program && ./01_first_classroom_program`
2. [`02_basic_input_output_math.cpp`](./01_CPP_SOURCE_CODE/02_basic_input_output_math.cpp) — `g++ -std=c++20 -Wall -Wextra -pedantic 02_basic_input_output_math.cpp -o 02_basic_input_output_math && ./02_basic_input_output_math`
3. [`03_void_main_compile_error.cpp`](./01_CPP_SOURCE_CODE/03_void_main_compile_error.cpp) — `g++ -std=c++20 03_void_main_compile_error.cpp` *(Intentional Compile-Time Error Demonstration — Category B)*
