# 02_PROGRAMS — 02 DATA TYPES AND VARIABLES (C++ Source Programs & PDF Code Guides)

This folder contains 3 self-contained C++ source programs for **02 DATA TYPES AND VARIABLES**, organized into subfolders:

## Subfolders inside `02_PROGRAMS/`
1. [`01_CPP_SOURCE_CODE/`](./01_CPP_SOURCE_CODE/README.md) — All 3 compilable `.cpp` source files (plus intentional `_compile_error.cpp` classroom demonstrations where applicable).
2. [`02_PDF_PROGRAM_GUIDES/`](./02_PDF_PROGRAM_GUIDES/README.md) — Printable, syntax-highlighted PDF reference sheet containing all 3 C++ programs with line-by-line commentary.

2. [`02_const_and_constexpr.cpp`](./01_CPP_SOURCE_CODE/02_const_and_constexpr.cpp) — `g++ -std=c++20 -Wall -Wextra -pedantic 02_const_and_constexpr.cpp -o 02_const_and_constexpr && ./02_const_and_constexpr`
3. [`03_narrowing_conversion_compile_error.cpp`](./01_CPP_SOURCE_CODE/03_narrowing_conversion_compile_error.cpp) — `g++ -std=c++20 03_narrowing_conversion_compile_error.cpp` *(Intentional Compile-Time Error Demonstration — Category B)*
